01 / how it works

Delete what's stale. Keep the rest exactly.

Summaries are lossy: a file path, exact error, or constraint can vanish when it matters later. This plugin never rewrites. It only removes tool calls and results that are no longer needed.

  1. 01

    Trigger

    /compact, or automatically when context reaches 60%.

  2. 02

    Redact

    Secrets and PII are stripped from the outbound copy. Your transcript is untouched.

  3. 03

    Score

    jev asks the Jev model about every call in one fast request, or local applies offline rules.

  4. 04

    Decide

    Each call is kept, has its result truncated, or is removed with its result. Recent messages are pinned.

  5. 05

    Apply or fall back

    Enough savings: the pruned, verbatim history replaces the summary. Otherwise: Claude's built-in summary.

kept verbatimnever rewritten
  • Every user and assistant text message, in order
  • The first message and the newest messages (pinned)
  • Tool calls and results still needed for the task
  • In local mode: errors, edits, and anything uncertain
removed or truncatedre-runnable if needed
  • Tool calls that no longer matter, with their results
  • Stale results, cut to their first 300 characters plus a note
  • In local mode: old, successful duplicate file reads
  • Nothing at all when savings fall below the minimum
02 / features

Built to be trusted with your context.

core

Verbatim pruning

Deletes whole tool calls or truncates results. Kept messages are the original objects, unchanged.

jev mode

One fast request

The Jev model scores every call and result against the whole conversation, with a 30-second timeout.

local mode

Offline, no API key

Deterministic rules with zero network requests. Conservative by design: only old duplicate reads go.

security

Outbound redaction

Bearer tokens, API keys, passwords, private keys, emails, and phone numbers are removed before anything is sent.

safety

Safe fallback

Errors, timeouts, or savings below the minimum hand off to Claude's built-in summary. Compaction never breaks.

metrics

Per-run metrics

Tokens before and after, reduction, latency, requests, and provider usage when reported. Nothing invented.

quality

Retention benchmark

npm run bench checks that labelled critical calls survive and that tasks still pass, in both modes.

history

Local run history

Every run is appended to .jev/runs.jsonl with decisions, never prompts or tool output.

dashboard

Private dashboard

npm run dashboard serves this page on 127.0.0.1 with per-run decision details.

03 / quick start

Running in two minutes.

Function hooks are an early-access Claude Code feature (2.1.274+), so enable them first.

1

Enable function hooks

Add this to ~/.claude/settings.json. The API key is only needed for Jev mode.

{
  "env": {
    "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1",
    "TYPESAFE_API_KEY": "<your key, jev mode only>"
  }
}
2

Install the plugin

From a terminal, or as slash commands inside Claude Code.

claude plugin marketplace add gaaurav03/Jev-Project
claude plugin install fast-jev-plus@fast-jev-plus
3

Pick a mode

Open /config and set mode to jev (more savings, needs a key) or local (offline, most conservative). Restart Claude Code.

4

Compact

Run /compact, or let it trigger at 60% context. The toast reports the result:

kept 20/140 messages, no summary (98% reduction; 60 call_dropped …)
5

Measure it yourself (optional)

From a clone of the repository:

npm install
npm run bench -- --mode both   # retention + reduction
npm run dashboard              # private dashboard on 127.0.0.1

09 / privacy

Privacy by design.

Community totals come from anonymous, opt-out telemetry. The first compaction only shows a notice; nothing is sent until the next one.

sent per compaction

  • A random install ID, not tied to you or your machine
  • Plugin version, mode, and applied or fallback
  • Estimated tokens before and after, and latency

never sent

  • Prompts, messages, code, or tool output
  • File names, paths, or tool names
  • API keys, run IDs, or IP addresses

Opt out with JEV_TELEMETRY=0, DO_NOT_TRACK=1, or the plugin's telemetry option in /config. Benchmark runs are never sent.

This page shows constrained metrics only. Token figures are estimates; API usage and cost stay unknown unless the provider reports them.
